# 项目愿景与设计意图

## 产品定位

- 本项目是面向 XJTLU 学生的文字类生存抉择 Web 游戏，玩法上融合《中国式家长》的长期规划感与《王权》的事件选择反馈。
- 主要受众是大一新生与早期有申研意向的学生，目标是在可玩内容中提供可迁移到现实决策的经验。

## 核心设计哲学

### 1) 教育性与趣味性合一

- 老师提供的《申研知识库》不直接以说教方式出现，而是融入事件情景、选项和后果。
- 玩家在游戏里“先踩坑”，通过标签、数值和结局反馈理解现实风险。
- 例如“中介风云”事件链会根据选择结果赋予“黑中介受害者”等标签，并影响最终录取结局。

### 2) 真实校园语境作为叙事载体

- 游戏主界面使用校园平面图，而不是纯连续事件流。
- 这样既能帮助新生认识校园建筑，也能让建筑天然承载主题化叙事。
- 建筑承担“知识场景入口”的作用，例如：
  - 宿舍：室友关系与生活管理建议
  - CB：雅思考试政策与备考策略
  - FB：储物柜借用规则等校园生活信息
  - EB：实验室规范与工程学习情境

### 3) 系统层与叙事层分离

- 数值平衡、标签机制和结局计算属于系统设计。
- 文案层重点负责代入感、可读性和情境真实性。
- 两者协作但不互相污染：不把系统公式硬写进剧情，也不让剧情口号主导数值设计。

## 当前 Demo 范围（4 个月版）

- 回合结构压缩为 4 个月，聚焦“申研关键节点”体验。
- 核心链路包含：中介风云、雅思考位压力、期末清算与结局复盘。
- 节奏参考文档：`docs/gameplay-flow-4-months.md`。

## 未来路线（可能方向）

以下内容属于可扩展方向，不代表版本承诺：

### 1) 软背景系统

- 将科研、实习、推荐信质量、项目经历等纳入隐藏维度。
- 通过软背景影响录取区间，使结局逻辑更贴近真实申研。

### 2) 院系扩展

- 解锁更多院系作为可选开局。
- 不同院系拥有不同核心数值权重和专属事件库。
- 示例：设计学院偏作品集与评图反馈，商学院偏团队协作与汇报压力。

### 3) 时间跨度扩展为本科四年

- 从当前申请季压缩体验扩展到完整本科周期。
- 引入关键分岔决策点，提高重复游玩价值与科普广度，例如：
  - 大一升大二：太仓校区相关选择
  - 大二升大三：2+2 / 4+0 路径选择

### 4) 建筑事件丰富化

- 按建筑主题持续扩展事件池，形成“建筑 = 情境入口”的稳定设计范式。
- 在保证趣味性的前提下，逐步覆盖更多高频学生问题与误区。
